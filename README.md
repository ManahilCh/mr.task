# Mr.Task

Mr.Task is a professional AI-powered team task management system inspired by Trello.

## Features

- JWT Authentication
- Team task management
- Create, update, delete tasks
- Drag and drop Kanban board
- Search and filter tasks
- Due date tracking
- Priority management
- AI Butler suggestions
- Checklist generation
- Team members page
- Analytics dashboard
- Power-Up integrations section
- Responsive design
- Professional dark theme

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- Framer Motion
- dnd-kit
- Redux Toolkit
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Multer
